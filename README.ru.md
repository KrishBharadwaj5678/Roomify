## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/features.gif" width="35"/> Возможности

| Возможность | Описание |
| --- | --- |
| 🏠 **AR-визуализация комнаты** | Просматривайте современные дизайны комнат непосредственно в реальном пространстве |
| ⏭️ **Следующий и предыдущий** | Легко переключайтесь между различными дизайнами комнат |
| 🔊 **Управление звуком** | В любой момент включайте или выключайте звук |
| 📸 **Снимок экрана** | Легко сохраняйте понравившиеся виды комнат |
| 🕹️ **Управление джойстиком** | Приближайте и отдаляйте вид по вертикали, а также поворачивайте его влево и вправо |
| 🔄 **Сброс** | Сбрасывайте текущий сеанс и начинайте исследование заново |

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Roomify.git
````

### 2️⃣ Переход в папку проекта

```bash
cd Roomify
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите клонированную папку **Roomify**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Roomify

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте **Roomify** и предоставьте доступ к камере для работы функций дополненной реальности.

2️⃣ Просканируйте окружающее пространство, чтобы обнаружить поверхности.

3️⃣ Нажмите на обнаруженную поверхность, чтобы разместить выбранный дизайн комнаты.
