## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Como começar

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Roomify.git
````

### 2️⃣ Acessar o diretório do projeto

```bash
cd Roomify
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **Roomify** clonada.

### 4️⃣ Abrir o projeto

- Depois que o Unity terminar de importar os arquivos do projeto, abra a cena principal na pasta **Assets**.

### 5️⃣ Executar o projeto

- Clique no botão **Play** no Unity Editor para iniciar o Roomify.

<img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como funciona

1️⃣ Abra o **Roomify** e conceda permissão para acessar a câmera para utilizar os recursos de AR.

2️⃣ Escaneie o ambiente ao seu redor para detectar superfícies.

3️⃣ Toque em uma superfície detectada para posicionar o design de ambiente selecionado.
