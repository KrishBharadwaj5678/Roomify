## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| --- | --- |
| 🏠 **ARルームビジュアライゼーション** | 現実の空間にモダンなルームデザインを表示して体験できます |
| ⏭️ **次へ・前へ** | 複数のルームデザインを簡単に切り替えられます |
| 🔊 **サウンドコントロール** | いつでもサウンドをオン・オフできます |
| 📸 **キャプチャ** | お気に入りのルームビューを簡単に保存できます |
| 🕹️ **ジョイスティック操作** | 上下方向にズームイン・ズームアウトしたり、左右に視点を回転させたりできます |
| 🔄 **リセット** | 体験をリセットして、もう一度探索を始められます |

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Roomify.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Roomify
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**Roomify**フォルダを追加します。

### 4️⃣ プロジェクトを開く

- Unityによるプロジェクトファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してRoomifyを起動します。

<img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

1️⃣ **Roomify**を開き、AR機能を使用するためにカメラへのアクセスを許可します。

2️⃣ 周囲をスキャンして、床や壁などのサーフェスを検出します。

3️⃣ 検出されたサーフェスをタップして、選択したルームデザインを配置します。
