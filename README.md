| ⏭️ **Next & Previous** | Easily switch between different room designs |

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Roomify.git
```

### 2️⃣ Navigate to the Project

```bash
cd Roomify
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **Roomify** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Roomify

## <img src="https://github.com/KrishBharadwaj5678/Roomify/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

1️⃣ Open **Roomify** and grant camera permissions for AR functionality.

2️⃣ Scan your surroundings to detect surfaces.

3️⃣ Tap on a detected surface to place the selected room design.
